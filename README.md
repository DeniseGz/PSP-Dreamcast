## 🌸 Overview
**PSP Rosita** is a front-end portfolio project built with vanilla web technologies. It blends retro nostalgia (inspired by classic portable consoles) with a soft pastel Y2K aesthetic, allowing users to interactively navigate through 6 distinct virtual gaming scenes.

## ✨ Features
* **Skeuomorphic Retro Design:** Custom pink pastel chassis, physical button styling, and a retro LCD screen with immersive borders.
* **Interactive Navigation:** Switch between scenes seamlessly using the on-screen D-pad, action buttons (`✕`, `○`), or the bottom quick-selection tabs.
* **6 Curated Universes:**
  1. *NieR:Automata* (A2)
  2. *Resident Evil* (Leon S. Kennedy)
  3. *Elden Ring* (Campfire Zone)
  4. *Spyro The Dragon*
  5. *Infinity Nikki*
  6. *Frutiger Aero / Aerowave*

## 🛠️ Built With
* **HTML5:** Core structure of the portable console and UI layout.
* **CSS3:** Advanced styling, Flexbox, custom 3D shadows, and retro aesthetic styling.
* **JavaScript (Vanilla):** Dynamic scene-switching logic and event listeners.

## 🚀 Getting Started
To test or run this project locally on your machine:

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (Google Chrome, Firefox, Edge).
